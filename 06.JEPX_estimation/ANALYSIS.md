# JEPXスポット価格予測と蓄電池スケジューリング 解析レポート

作業日: 2026-09-13 〜 09-15
対象: 東京エリア、JEPXスポット市場および需給調整市場（一次調整力）

> **改訂履歴**
> - 2026-09-15: 気象予報データにリークが判明したため全面的に再実行。`previous_day1`（対象時刻の24時間前発行）は入札締切（前日10時）後に発行された予報を含むため、`previous_day2`（48時間前発行）に差し替えた。詳細は 3.5 節。主要な結論はいずれも維持された。

---

## 0. 要約

前日10時の入札締切までに入手できる情報だけでJEPXスポット価格を予測し、その予測を蓄電池の充放電計画（LP）に通して収益で評価した。主な結果は以下。

1. **実運用の情報制約を課しても予測精度はほとんど落ちない**。締切制約の合計影響は点予測でRMSE -0.5%、q50で -1.1%。気象予報誤差だけを取り出すと +1.6%（点予測）/ +2.6%（q50）。
2. **予測精度と収益は一致しない**。前日コピー（persistence D-1）はMAEで前週同曜日コピー（D-7）に勝つが、収益では12%負ける。全コマを一律+5円ずらした予測はRMSE 5.00で完全予知の99.8%の収益を出す。
3. **損失関数に順序項を入れると収益が上がる**。MSE＋pairwise ranking のハイブリッド損失で、完全予知比 63.9% → 67.8%（5シード、α比較で p=0.0005）。このときMAEは悪化する。
4. **スポットアービトラージ単独は劣化コストを入れると赤字**。損益分岐は16.3円/kWhで、実際の劣化コスト13〜22円/kWhと重なる。
5. **現在の収益の大半は需給調整市場（一次調整力）が占める**。スポット1,407円/日に対し調整力10,572円/日。ただし応札比が2年で0.011→0.972に達し飽和目前で、この収益は一時的と見られる。

## 1. 問題設定

### 1.1 市場の時間構造

```
前日 10:00  JEPXスポット 入札締切
前日 10:30  スポット約定結果 公表
前日 11:30  需給調整市場 入札開始
前日 14:00  需給調整市場 入札締切
前日 15:00  需給調整市場 約定
   当日     実需給
```

スポットが先、需給調整市場が後。したがってスポット入札時点では調整力価格は未確定であり、調整力入札時点ではスポット価格は確定している。

### 1.2 既存分析（06）の問題

既存の `feature_metadata.json` の leak_policy には以下の記述があった。

> day-ahead: features at date D use only data with date <= D-1 (TEPCO/weather actuals at t are treated as forecast...)

日付のリークは避けているが、東電の需給実績と気象の実測値を「予報として扱う」ことにしていた。実運用ではこれらは予測時点で入手できない。

## 3. 情報境界の設計

### 3.1 前日10時に入手できるもの

| データ | 入札時点で入手可 | 根拠 |
|---|---|---|
| JEPX価格 D-1分 | ○ | D-2の10:30に約定確定 |
| 気象実測 | × | 事後のみ |
| 気象予報（48時間前発行） | ○ | Open-Meteo previous_runs（3.5節） |
| 東電需給実績 D-1分 | **×** | 前日分の公開は翌朝6時頃 |
| 東電需給実績 D-2分 | ○ | 同上 |
| 東電の翌日需給予測 | **×** | AREA_ONCE_YOSOKU は前日23:12公表で締切後 |

**前日10時時点で公開されている翌日需給予測は、調べた範囲では存在しない。** 東電の翌日予測は前日23時台の公表で締切に間に合わない。月次アーカイブに残る AREA_YOSOKU も更新時刻が対象日当日の23:41で、前日10時時点の版は復元できない。

### 3.2 4条件

気象データソースと需給情報を分離するため4条件を作った。

| 条件 | 気象 | 需給 |
|---|---|---|
| era5_actual | ERA5実測 | 同時刻の実績 |
| analysis | previous_runs 最新ラン | 同時刻の実績 |
| fc_weather | previous_runs 48時間前発行ラン | 同時刻の実績 |
| **gateclose** | previous_runs 48時間前発行ラン | D-2以前のラグ |

era5_actual と analysis の差はデータソース差のみ、analysis と fc_weather の差が純粋な予報誤差、fc_weather と gateclose の差が需給情報の制約。

### 3.3 データソース間の系統差

ERA5 と Open-Meteo の予報モデルの間には系統差がある。日射で平均差 -68.8 W/m²、MAE 114.3。これは予報誤差ではなくデータソースの違いであり、両者を比較すると「実測 vs 予報」の測定にならない。このため予報誤差の測定は同一モデル系列内（previous_runs の最新ラン vs 過去ラン）で行った。

### 3.4 気象予報の誤差（48時間前発行）

期間 2021-04-01〜2026-09-13、95,616行。

| 変数 | MAE | RMSE |
|---|---|---|
| 気温 | 1.176 | 1.674 |
| 風速 | 1.820 | 2.646 |
| 日射 | 89.287 | 160.101 |

日射を昼間9-16時に限ると **MAE 115.6 W/m²、RMSE 171.5**、実測平均452.3に対して相対RMSE **38%**。

### 3.5 previous_day1 のリークと修正

**当初 `previous_day1` を使用していたが、これはリークを含んでいた。**

Open-Meteo のドキュメントによれば、

> `_previous_day1` is the value that was predicted **24 hours before valid time**, `_previous_day2` 48 hours before

つまり固定リードタイムであり、**対象時刻の24時間前に発行された予報**が入る。対象日 D の入札締切は D-1 10:00 なので、

```
D 00:00 のコマ → D-1 00:00 発行  … 締切前、OK
D 10:00 のコマ → D-1 10:00 発行  … 締切と同時
D 23:30 のコマ → D-1 23:30 発行  … 締切の13.5時間後、NG
```

**48コマ中38コマ（10:30〜23:30）で、入札締切後に発行された予報を使っていた。**

実データにも痕跡があり、previous_day1 の気温絶対誤差は前半12時間で0.758℃、後半12時間で0.275℃と、後半のほうが小さい。発行時刻が対象時刻に近いためである。

修正として `previous_day2`（48時間前発行）に差し替えた。これなら D 23:30 のコマでも D-2 23:30 発行となり、全コマで締切前に入手できる。

誤差は以下のように悪化した。

| 変数 | previous_day1（リークあり） | **previous_day2（修正後）** |
|---|---|---|
| 気温 MAE | 1.036 | **1.176** |
| 日射 MAE | 25.872 | **89.287** |
| 日射 9-16時 相対RMSE | 24% | **38%** |

なお厳密には「D-1 10:00 より前の最新ラン」＝リードタイム14〜38時間の予報が使えるはずで、48時間固定は保守的すぎる。正確に行うには Single Runs API で特定のモデルランを取得する必要があるが、実装コストの都合で見送った。**本解析の予測精度は、この点で過小評価になっている可能性がある。**

### 3.6 4条件の比較結果

期間を2021-04-01以降に揃え、test = 2026-03-13〜2026-09-13（8,880コマ）。

test RMSE の変化率:

| 比較 | 点予測 | q50 | q10 | q90 |
|---|---|---|---|---|
| 気象データソースの差（ERA5→予報モデル） | -0.7% | -2.8% | -4.2% | -3.9% |
| **気象予報誤差の影響** | **+1.6%** | **+2.6%** | +3.2% | -4.1% |
| 需給情報がD-2までに限られる影響 | -2.1% | -3.6% | -7.3% | **+18.1%** |
| **締切制約の合計** | **-0.5%** | **-1.1%** | -4.3% | +13.3% |

gateclose 条件の絶対値（test）:

| モデル | MAE | RMSE | sMAPE |
|---|---|---|---|
| lgbm_point | 3.545 | 5.355 | 21.82 |
| lgbm_q50 | 3.422 | 5.119 | 21.36 |
| lgbm_q10 | 5.884 | 7.894 | 38.68 |

| seasonal_naive_d7 | 4.964 | 7.312 | 29.70 |

**所見**

- 気象予報誤差の影響は点予測で+1.6%、q50で+2.6%。日射の昼間相対RMSEが38%あるにもかかわらず、価格予測への影響は限定的。
- 需給をD-2ラグに変えると点予測・q50は改善するが、**q90（上側分位点）は18.1%悪化**する。高値の予測は同時刻の需給実績に依存していた。
- ERA5より予報モデルのほうが価格予測には良い（-0.7〜-4.2%）。既存06がERA5を使っていたことはわずかに不利に働いていた。
- **締切制約の合計はむしろ精度を改善している**（点予測 -0.5%）。予報誤差による悪化を、需給ラグの追加による改善が上回る。

**留保**: 需給の比較は特徴量構成も同時に変わっている（31列→35列、D-2ラグを9列追加）ため、「需給情報の制約」だけの効果には帰属できない。

### 4.2 sMAPEの解釈

sMAPE 21.2（q50）は価格帯別に分解できる（旧データでの計測、傾向は変わらない）。

| 価格帯 | 件数割合 | sMAPE | MAPE | MAE |
|---|---|---|---|---|
| <1円 | 1.9% | 192.6 | 43,912 | 6.30 |
| 1-5円 | 1.1% | 124.1 | 474.2 | 7.86 |
| 5-15円 | 14.8% | 24.7 | 29.3 | 3.10 |
| **15-30円** | **73.4%** | **13.3** | 12.9 | 2.64 |
| ≥30円 | 8.7% | 30.1 | 24.9 | 9.13 |

## 5. 蓄電池スケジューリングと収益評価

### 5.1 設備条件

低圧系統用蓄電所（50kW未満）を想定。

| パラメータ | 値 | 根拠 |
|---|---|---|
| 出力 | 49.5 kW | 低圧＝50kW未満。実在構成（GoodWe ESA等） |
| 容量 | 200 kWh | 49.9kW/100〜200kWh が標準構成 |
| 往復効率 | 87% | 実機は85〜90% |
| SOC範囲 | 10〜90%（実効160kWh） | 一般的な運用範囲 |
| 初期投資 | 1,800〜2,700万円 | 100-200kWh構成の相場 |

### 5.2 最適化の定式化

各日48コマを1つのLPとして解く。日跨ぎの持ち越しなし（日初=日末SOC）。

```
変数  pc_t 充電電力[kW], pd_t 放電電力[kW]
目的  max Σ p_t·(pd_t − pc_t)·Δt − λ·Σ pd_t·Δt
制約  0 ≤ pc_t, pd_t ≤ P
      E_MIN ≤ E_START + Σ(η·pc_i − pd_i/η)·Δt ≤ E_MAX
      Σ(η·pc_i − pd_i/η)·Δt = 0
```

λ は放電量あたりの劣化コスト。`scipy.optimize.linprog`（HiGHS）で求解。

**損益分岐点**: oracle 59.1 / q50 **16.3** / point 13.5 / naive 8.5 円/kWh

実際の劣化コストは、初期投資2,000万円・容量200kWh・サイクル寿命6,000回として **1kWhあたり約17円**（13〜22円のレンジ）。q50の損益分岐点16.3円/kWhはこのレンジの中央にあり、**電池の調達価格と寿命次第で黒字にも赤字にもなる**。

投資回収の観点では、粗利1,484円/日 × 365 = 約54万円/年に対し設備投資1,800〜2,700万円であり、**スポット単独では回収不能**。

### 5.6 最適化の定式化の妥当性

LPの緩和と日単位分割が結果に影響していないかを検証した。

**同時充放電**

LPでは同一コマで充電と放電が同時に正になりうる（物理的には不可能）。実際に発生しているか確認した。

```
オラクル : 同時充放電のコマ 0 / 8,880 (0.000%)
q50      : 同時充放電のコマ 0 / 8,880 (0.000%)
```

**1件も発生していない。** 価格が正で往復効率損失があるため、最適解では自然に排除される。バイナリ変数を導入したMILP化は不要。

**日跨ぎ持ち越し**

現状は日初=日末SOCで日単位に分割している。複数日をまとめて解いた場合との差（オラクル価格）:

| 最適化の窓 | 収益 | 現状比 |
|---|---|---|
| 1日（現状） | 2,288 円/日 | — |
| 2日 | 2,295 円/日 | +0.3% |
| 7日 | 2,319 円/日 | **+1.3%** |

実効容量160kWhに対し1日1.33サイクル使用しており、持ち越す余地が小さい。4時間持続の設備では日内で使い切る構造のため、**日単位分割による損失は1.3%程度**にとどまる。

**所見**: 収益を増やす方向の改善余地は最適化側にはほぼない。改善余地は予測側（VCR 67.8% → 100% の差、日次804円）に集中している。ただし劣化モデルの非線形性（Rainflow counting）は収益改善ではなく評価の現実性の問題として残る。

## 6. 予測精度と収益の乖離

### 6.1 順序保存の実験

真の価格に様々な変換を加えて収益を測った（185日）。

| 予測の作り方 | RMSE | Spearman | 収益(円/日) | VCR |
|---|---|---|---|---|
| 真の価格 | 0.00 | 1.000 | 2,288 | 100.0% |
| **全コマ1.5倍** | **10.44** | 1.000 | **2,288** | **100.0%** |
| 全コマ一律+5円 | 5.00 | 1.000 | 2,284 | 99.8% |
| 小さいノイズ σ=1 | 0.99 | 0.917 | 2,175 | 95.0% |
| 実際のq50モデル | 5.12 | 0.744 | 1,484 | 64.9% |
| ランダムノイズ（同RMSE） | 5.03 | 0.618 | 1,157 | 50.5% |

**RMSEが2倍悪い予測（全コマ1.5倍）が、収益では2倍良い。** LPは価格の大小関係しか使わないため、正の定数倍しても最適解が変わらない。

### 6.2 順序だけでは足りない

順序のみを保存した変換で収益を測ると、100%には届かない。

| 予測の作り方 | 順位相関 | 収益 | オラクル比 |
|---|---|---|---|
| 真の価格 / 1.5倍（順序＋比率） | 1.000 | 2,288 | **100.0%** |
| 順位そのもの 1..48 | 1.000 | 2,097 | 91.6% |
| 順位の2乗 | 1.000 | 2,032 | 88.8% |
| 順位の指数 | 1.000 | 2,011 | 87.9% |
| 変動を0.3倍に圧縮 | 1.000 | 2,000 | 87.4% |

**順序が収益の88〜92%を決め、残り8〜12%は価格の比率が決める。** 往復効率87%なので「放電価格 > 充電価格 × 1.15」でないと損をし、この判断には絶対値の比率が必要。

この結果は、純粋なランキング学習では上限91.6%であり、ハイブリッド損失（MSE＋ランキング）が必要であることを意味する。

### 6.3 実在モデルでの逆転

人工的な操作を使わない例として、2つのpersistenceで順位が逆転する。

```
persistence D-1（前日コピー）    MAE 4.34（良い） → 収益 976円/日、VCR 42.7%
persistence D-7（前週同曜日）    MAE 4.96（悪い） → 収益 1,091円/日、VCR 47.7%
```

MAE・RMSEではD-1が勝ち、Kendall τ・VCRではD-7が勝つ。前日コピーは値の水準が近いが曜日が変わると日内の形が崩れ、前週同曜日は水準が外れても平日・休日のパターンが保たれる。

### 6.4 先行研究

| 出典 | 内容 |
|---|---|
| arXiv 2604.12082 | 独・スイス市場（FCR/aFRR/DA/XBID）。**Kendall τ が MAE より収益を予測する**。τ ≥ 0.85〜0.95 でVCR 97〜100%。persistence予測はMAEでは良好でもτ≈0でVCR 32.8% |
| arXiv 2305.00362 | PJM市場。decision-focused learning（hybrid loss = MSE + surrogate regret）。**DFPはRMSE 0.294でMLPの0.0287の10倍悪いが、収益は29.86 vs 28.14ドル/日で上回る** |
| IJEPES 2024（S0142061524001042） | イベリア市場、Rainflow劣化モデル。**リスク尺度（CVaR等）を確率的最適化に加えると点予測の決定論的戦略より悪化する** |

本解析で観測した現象は独立に先行研究で報告されている。指標としては VCR（Value Capture Ratio）と Kendall τ が使われている。

## 7. 損失関数の設計

### 7.1 モデル構造

順序は「同じ日の48コマの間の関係」であるため、コマごとに独立予測するLightGBMでは損失に書けない。48コマ同時出力のMLPに変更した。

```
入力: 日次固定特徴量 20 + コマ依存特徴量 15×48 = 740次元
出力: 48次元
サンプル: 1,992日（train 1,717 / val 90 / test 185）
```

この定式化はEPFの標準（Lago et al. のDNN/LEARも1日24時間を同時出力）。

### 7.2 損失

```
loss = α · MSE(pred, true) + (1 − α) · pairwise_rank_loss(pred, true)

pairwise_rank_loss:
  dp = pred_i − pred_j,  dt = true_i − true_j
  loss = softplus(−dp · sign(dt))          # RankNet型 logistic ranking loss
  weight = |dt|^β                          # β=0 で重みなし
```

日内48コマの全ペア（1,128組）について計算。価格は標準化。

### 7.3 α の効果（β=0）

1シードでの掃引:

| α | MAE | Kendall | 収益/日 | VCR |
|---|---|---|---|---|
| 1.0（純MSE） | 4.77 | 0.594 | 1,466 | 64.1% |
| 0.9 | 4.50 | 0.591 | 1,488 | 65.0% |
| 0.7 | 4.96 | 0.608 | 1,536 | 67.1% |
| 0.5 | 4.99 | 0.612 | 1,521 | 66.5% |
| 0.3 | 4.71 | 0.624 | 1,535 | 67.1% |
| 0.1 | 6.53 | 0.630 | 1,485 | 64.9% |
| 0.0（純ランキング） | **16.79** | 0.623 | 1,286 | **56.2%** |

5シードでの検証:

| α | VCR平均 | Kendall | MAE |
|---|---|---|---|
| 1.0 | 64.84% ± 0.53 | 0.595 | **4.52** |
| 0.5 | 67.15% ± 0.80 | 0.620 | 4.85 |
| **0.3** | **67.34% ± 0.90** | **0.625** | 4.98 |

```
α=0.3 − α=1.0 の VCR差: +2.50pt
全5シードで改善（+3.2, +1.7, +2.3, +2.5, +2.8）
対応ありt検定 p = 0.0005
```

**αを下げるとMAEは悪化しVCRは改善する**というトレードオフが、統計的に有意な形で出た。ただし α=0（純ランキング）ではスケールが壊れ（MAE 16.79）、VCRは56.2%まで急落する。

### 7.4 β（ペア重み）の効果

手動で β=0（重みなし）と β=1（価格差に比例）を比較すると、β=1 は全体に悪化した（α=0.3で -1.99pt、Kendall 0.636→0.618）。価格差が大きいペア＝スパイク周辺に学習が集中し、予測困難な領域に引っ張られたと考えられる。

しかしOptunaでβを連続値として探索すると、**上位5試行のβはすべて0.37〜0.54**（0.406, 0.377, 0.468, 0.427, 0.537）であった。β=0とβ=1の二択では最適点を見逃していた。

### 7.5 ハイパーパラメータ探索

Optuna（TPE）60試行。選択基準は **validation の VCR**。

探索空間: α 0.05-1.0、β 0.0-1.0、層構成4種、dropout 0-0.45、lr 1e-4〜3e-3（log）、wd 1e-6〜1e-3（log）

最良パラメータ:
```
α = 0.775   β = 0.406   層 1024-512   dropout 0.403   lr 1.3e-4   wd 5.2e-4
```

test評価（5シード）:

| seed | VCR | MAE | Kendall | 収益/日 |
|---|---|---|---|---|
| 0 | 68.40% | 4.20 | 0.619 | 1,565 |
| 1 | 67.60% | 4.27 | 0.609 | 1,547 |
| 2 | 66.88% | 4.51 | 0.610 | 1,530 |
| 3 | 67.82% | 4.14 | 0.614 | 1,552 |
| 4 | 68.21% | 4.19 | 0.617 | 1,561 |
| **平均** | **67.78% ± 0.53** | **4.26** | **0.614** | **1,551** |

**注意**: validation VCR は 88.26% だったが test は 67.78%。60試行でvalを最大化したためvalの値は楽観的であり、報告に使えるのはtestのみ。

### 7.6 最終比較

| モデル | MAE | RMSE | Kendall τ | VCR | 収益/日 |
|---|---|---|---|---|---|
| persistence D-7 | 4.96 | 7.31 | 0.482 | 47.7% | 1,091 |
| **LightGBM (L2) 基準** | **3.54** | **5.36** | 0.593 | 63.9% | 1,461 |

ベースライン比 **+3.9pt（+90円/日）**。MAEではLightGBMが依然最良。

1台あたり年+3.3万円。アグリゲーション100台で年330万円、1,000台で3,300万円。予測モデルの複製コストはゼロであるため、台数が価値を決める。

## 9. 2市場の同時最適化

### 9.1 定式化

```
変数  pc_t 充電[kW], pd_t 放電[kW], r_t 上げ調整力提供量[kW]
目的  max Σ p_t·(pd_t − pc_t)·Δt + Σ q_t·r_t
制約  上げ余力     r_t ≤ P − pd_t + pc_t
      SOC範囲     E_MIN ≤ s_t ≤ E_MAX
      調整力の裏付け s_t − r_t·(5/60)/η ≥ E_MIN
      日初=日末    s_n = s_0
```

調整力価格の予測には前日同コマの約定価格を使用。評価期間 2026-03-14〜2026-07-31、122日。

### 9.2 結果（劣化コスト前）

| 戦略 | スポット | 調整力 | 合計 | 調整力平均kW | 放電量/日 |
|---|---|---|---|---|---|
| spot_only | 1,407 | 0 | 1,407 | 0 | 193.9 kWh |
| **reserve_only** | 0 | 10,572 | **10,572** | 49.5 | **0 kWh** |
| joint | 829 | 9,898 | **10,727** | 46.6 | 70.2 kWh |
| joint_oracle | 1,779 | 9,606 | 11,386 | 45.6 | 94.0 kWh |

**joint は spot_only の7.6倍**だが、その増分はほぼ全部が調整力由来。jointがスポットで稼ぐ829円に対し、調整力を46.6kWに減らした機会損失が674円で、差し引き155円しかない。

### 9.3 劣化コストを入れると（旧データでの計測）

| λ(円/kWh) | spot_only | reserve_only | joint |
|---|---|---|---|
| 0 | 1,405 | 10,572 | **10,734** |

| 17 | -1,815 | **10,572** | 9,585 |
| 25 | -3,331 | **10,572** | 9,044 |

調整力は容量提供のみで電池を消耗しないため、λ>0では reserve_only が joint を上回る。


自己相関（同コマ）: D-1 で 0.472、D-2 で 0.320、D-7 で 0.176。スポット価格に比べ弱い。
募集量との相関 0.455、応札/募集比との相関 -0.435。

### 10.2 結果（train 76日 / val 30日 / test 31日）

| モデル | MAE | RMSE | MAE/平均 |
|---|---|---|---|
| persistence D-1 | 1.658 | 2.265 | 35.1% |
| persistence D-7 | 1.903 | 2.643 | 40.2% |
| 前日の日平均 | 1.676 | 2.228 | 35.4% |
| **全期間平均（定数）** | **1.547** | 2.256 | **32.7%** |
| LightGBM | 1.539 | 2.242 | 32.5% |
| LightGBM（募集量なし） | 1.539 | 2.239 | 32.5% |

LightGBM は iter=1 で早期停止し、実質的に定数を返した。募集量の有無で差がない。

**調整力価格は、このデータ・特徴量では予測できていない。** 原因は train が76日しかないこと、自己相関が弱いことと考えられる。

ただし `reserve_only`（常に全出力を調整力に出す）が joint とほぼ同じ収益であったことから、**調整力は「常に全部出す」が最適に近く、価格予測の必要性が構造的に小さい**とも言える。

## 11. 限界と留保

### 11.1 モデルの仮定

| 仮定 | 内容 | 影響 |
|---|---|---|
| **price taker** | 出せば必ず市場価格で約定する | JEPXスポットは一律価格なので妥当。**ペイアズビッドの需給調整市場では不適切**で、入札価格の決定問題を消している |
| 調整力の応動を無視 | 容量対価のみ計上、指令による充放電を計上しない | 9.5節の感度分析で u<60% なら結論不変 |
| 日跨ぎなし | 日初=日末SOC | 実運用では持ち越しがありうる |
| 劣化は放電量に線形 | Rainflow等のサイクル計数を使っていない | 先行研究ではRainflowが標準 |

### 11.2 データ・期間

- **気象予報は48時間前発行を使用**（3.5節）。実運用では14〜38時間前のランが使えるため、**本解析は予測精度を過小評価している可能性がある**。
- **test期間（2026-03〜09）は日内スプレッドの拡大期**（前年比+93%）。FY2023-2025の水準（8円台）なら収益は半分程度になる。
- 需給調整市場の現行制度データは **153日**。train 76日は明らかに不足。
- 予報データの制約により、学習は 2021-04-01 以降。2021年1月の歴史的高騰は含まれない。
- 単一エリア（東京）、単一設備構成のみ。

### 11.3 比較可能性

- JEPXには共通ベンチマークが存在せず、外部との精度比較ができない。
- 4条件の切り分けにおいて、需給の比較は特徴量構成も同時に変わっている。
- validation VCR（88.26%）は探索による楽観バイアスを含み、報告に使えない。
- 4.5節（用途別評価）、5.4節・9.3〜9.5節（感度分析）は旧データ（previous_day1）での計測値を残している。予測の変化が小さいため傾向は維持されると見られるが、数値は再計測していない。

### 11.4 未検証・未実装

- 入札曲線・価格感応度（Hirota 2025 が使用）の特徴量化。取得経路が未特定（`csv_read.php?dir=` 形式らしいがdir名不明）。
- decision-focused learning（regretを直接損失に）。骨格は用意したが未実装。
- 劣化の非線形モデル（Rainflow counting）。現状は放電量に線形で、深い放電の劣化を過小評価している可能性がある。なお MILP 化と日跨ぎ最適化は 5.6 節の検証により不要と判断した。
- 需給調整市場の入札価格決定（ペイアズビッドに対する最適応札）。
- τ*（充分性閾値）の同定。現状 τ=0.614 で先行研究の閾値 0.85-0.95 に遠く、精密化の実益が薄いため見送り。
- OCCTOの広域予備率公表システムに、前日10時より前に出る翌日需給見通しがあるかの確認。
- Single Runs API による正確なモデルラン指定（3.5節の保守性を解消するため）。
