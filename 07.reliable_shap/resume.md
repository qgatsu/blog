# 導入
今回の記事のモチベーション. 固くなりすぎずに以下を盛り込む.
- SHAP の大域重要度は `mean|SHAP|`（絶対寄与の平均）で見るのが定番.
- しかし平均は一次モーメント要約なので, 寄与分布がヘビーテールだと少数の外れ値サンプルに引っ張られる.
- 結果, 「大多数では寄与ほぼ0, ごく一部の外れ値でだけ巨大な寄与」を持つ特徴（＝外れ値検出専用の特徴）が過剰に高くランクされる.
- 棒グラフは分布を平均に潰すので, この危うさが隠れる.

# SHAPの復習と弱点
- SHAP の基本（Shapley value, 加法性 $\sum\phi=f-\mathbb{E}[f]$, 出力スケールに乗る）を簡潔に.
- 大域重要度 $I_j=\frac1n\sum_i|\phi_{ij}|$ の定義と, ヘビーテール脆弱性を数式で明示.
- 回帰で目的変数が極端なサンプルほど $|f-\mathbb{E}[f]|$ が大きく, それを検出する特徴が巨大な $|\phi|$ を得る.

# 提案: ブートストラップSHAPで信頼度を可視化する
- 行を復元抽出でブートストラップ → 毎回モデル再学習 → SHAP を計算, を B 回.
- 特徴ごとに 平均 / 95%CI / 変動係数 CV=sd/mean.
- 外れ値依存の特徴は「外れ値が入るか」で激変 → 高CV = 低信頼.
- 信頼度調整重要度 `mean/(1+CV)` で再ランキング.
- 軽量版（モデル固定・説明データのみ再抽出）との違いにも触れる.

# 分析
`01.reliable_shap_synthetic.ipynb` と `02.reliable_shap_jepx.ipynb` を参照.

## 合成データでの統制実証
- 真の重要度が既知（x1,x2,x3=広域, x_out=外れ値専用, x_noise=無効）.
- 標準 mean|SHAP| は x_out を1位に誤配置 → CV で低信頼を検出 → 調整ランクで是正.

## JEPX電力価格での実証
- 価格スパイクという本物の外れ値を持つ回帰. リーク列は除外.
- スパイク・ピーク検出系（prev_day_max, prev_day_band_peak, tepco_demand, tepco_solar）が高重要・高CV.
- 実データでは真の重要度が未知なので「過剰評価」の断定は避け, 信頼度という第2軸の価値を強調.

## ベースライン比較
- median|SHAP|, トリム平均: ランキングは部分的に直るが信頼度は定量化しない.
